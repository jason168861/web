# 享退休網站

這是依照 11 區塊資訊分工重整後的靜態網站。

## 打開方式

直接開啟 `index.html` 即可瀏覽網站。

## 主要檔案

- `index.html`：首頁內容與 11 區塊結構
- `css/styles.css`：原樣式與重整版覆蓋樣式
- `js/`：退休試算、財務健檢、投資性格測驗等互動工具
- `picture.jpg` / `picture.webp` / `picture-avatar.jpg`：顧問照片與大頭貼

## 內容節奏

明顯 CTA 僅保留在 Hero、服務方式、工具解鎖與最終 CTA。困擾、方法、案例、知識與關於我區塊只回答各自的單一問題。
